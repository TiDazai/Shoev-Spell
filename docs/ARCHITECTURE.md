# Shoev Spell: архитектура

Shoev Spell — отдельное локальное приложение, не системный словарь и не часть Shoev Switcher.

Поток обработки: глобальный event tap собирает текущее слово → SQLite проверяет точное совпадение → генератор строит варианты на одну вставку, удаление, замену или перестановку → оценка частотности выбирает только уверенный вариант → синтетические события заменяют слово перед пробелом.

Ограничения безопасности: приложение не обрабатывает Secure Event Input, не хранит полный набранный текст, по умолчанию отключено в терминалах и IDE, а журнал содержит только пары «ошибка → исправление».

Первая версия намеренно исправляет только расстояние Дамерау—Левенштейна 1. Для расстояния 2 понадобится заранее построенный SymSpell-индекс; полный перебор 7,1 млн записей во время печати недопустим.
