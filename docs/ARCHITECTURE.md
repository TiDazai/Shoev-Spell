# Shoev Spell: архитектура

Shoev Spell — отдельное локальное приложение, не системный словарь и не часть Shoev Switcher.

Поток обработки: глобальный event tap собирает текущее слово и ограниченный контекст предложения → SQLite проверяет точное совпадение → генератор строит варианты на одну вставку, удаление, замену или перестановку → оценка частотности выбирает только уверенный вариант → локальный пунктуационный движок добавляет однозначные запятые → синтетические события заменяют изменённый фрагмент перед пробелом. Перед переносом строки движок добавляет завершающую точку или вопросительный знак.

Пунктуационный движок основан на консервативных правилах русского языка: границы придаточных частей, противительные и повторяющиеся союзы, парные союзы, однозначные вводные конструкции и приветствия. Семантически неоднозначные случаи (сравнительные обороты с «как», большинство обособленных определений и обстоятельств) автоматически не меняются.

Ограничения безопасности: приложение не обрабатывает Secure Event Input, не хранит полный набранный текст, по умолчанию отключено в терминалах и IDE, а журнал содержит только пары «ошибка → исправление».

Первая версия намеренно исправляет только расстояние Дамерау—Левенштейна 1. Для расстояния 2 понадобится заранее построенный SymSpell-индекс; полный перебор 7,1 млн записей во время печати недопустим.
