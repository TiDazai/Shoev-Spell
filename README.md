# Shoev Spell

Локальная автоматическая проверка и осторожное исправление русских и английских слов, а также восстановление русской пунктуации во всех приложениях macOS, где разрешён глобальный ввод.

Текущий MVP использует встроенную базу из 7 120 939 записей, исправляет опечатки на расстоянии 1 только при высокой уверенности и расставляет однозначные запятые по контексту текущего предложения. Перед переносом строки приложение также добавляет точку или вопросительный знак, а начало ввода и первое слово после `.`, `?` или `!` начинает с заглавной буквы. Защищённые поля пропускаются, а журнал исправлений остаётся локальным.

## Установка

Скачайте `Shoev-Spell.dmg` со страницы Releases, откройте образ и перенесите приложение в `Applications`. При первом запуске разрешите «Мониторинг ввода» и «Универсальный доступ».

## Сборка

```bash
./scripts/setup-local-signing.sh
./scripts/build-app.sh
```

Готовое приложение появится в `dist/Shoev Spell.app`. При первом запуске macOS попросит разрешения «Мониторинг ввода» и «Универсальный доступ».
Скрипт автоматически собирает архив словаря из небольших частей репозитория, если его ещё нет локально.
Постоянная локальная подпись нужна для development-сборок: без неё macOS считает каждый новый бинарник другим приложением и сбрасывает доступ к мониторингу ввода и универсальному доступу.

Создание DMG:

```bash
./scripts/create-dmg.sh
```
