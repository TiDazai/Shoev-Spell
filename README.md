# Shoev Spell

Shoev Spell исправляет опечатки прямо во время набора на macOS и Windows. Работает с русским и английским текстом, помогает с русской пунктуацией и заглавными буквами.

Всё обрабатывается на компьютере. Интернет для исправлений не нужен, журнал тоже хранится локально.

## Что умеет

- Исправляет простые опечатки по встроенному словарю. Если подходящих вариантов несколько и выбор неочевиден, оставляет слово как есть.
- Ставит запятые в знакомых конструкциях: например, при вводных словах, обращениях и перед некоторыми союзами.
- Начинает ввод с заглавной буквы и делает то же самое после точки, вопросительного или восклицательного знака.
- При нажатии Enter добавляет точку или вопросительный знак, если в конце предложения ещё нет знака.

Исправления, пунктуацию и заглавные буквы можно включать отдельно через меню приложения.

С пунктуацией пока есть ограничения: она работает по набору правил и не всегда верно понимает смысл фразы. В сложных предложениях запятые лучше проверить самому. Приложение обрабатывает текущий набор, а не вычитывает весь открытый документ.

Защищённый ввод пропускается. Терминалы и некоторые редакторы кода по умолчанию исключены из обработки.

Для исправлений поле должно предоставлять текст и положение курсора через «Универсальный доступ». Если прочитать их нельзя, приложение пропускает ввод. При удалении текста контекст сбрасывается; отслеживание возобновляется с нового слова. Выделенный текст и части уже существующего слова автоматически не капитализируются.

## Установка

Откройте [Releases](https://github.com/TiDazai/Shoev-Spell/releases) и выберите файл для своей системы: `Shoev-Spell-x64.zip` или `Shoev-Spell.dmg`. Это один Shoev Spell с общими возможностями, словарём, версиями и релизами. ZIP распакуйте и запустите `Shoev Spell.exe`; DMG откройте и перетащите Shoev Spell в «Программы». Установка .NET не требуется.

Поддерживаются Windows 10/11 x64 и macOS 13 или новее. Приложения, запущенные в Windows от имени администратора, система не разрешает изменять обычному процессу; в таком случае Shoev Spell тоже нужно запустить от имени администратора.

При первом запуске на macOS понадобятся два разрешения:

- **Мониторинг ввода** — чтобы приложение получало нажатия клавиш.
- **Универсальный доступ** — чтобы оно могло заменять набранный текст. В новых версиях macOS этот раздел может называться «Управление устройством и доступ к данным».

Оба находятся в «Системные настройки → Конфиденциальность и безопасность». После выдачи разрешений перезапустите Shoev Spell.

Если исправления не работают, сначала проверьте, включены ли они в меню приложения. Затем проверьте разрешения. После замены сборки macOS иногда показывает включённый доступ, но продолжает его отклонять. В таком случае попробуйте выключить и снова включить разрешения для Shoev Spell, затем перезапустить приложение.

## Сборка

Windows:

```powershell
dotnet publish windows/ShoevSpell.Windows/ShoevSpell.Windows.csproj -c Release -r win-x64 --self-contained true
```

macOS:

На Mac с установленными инструментами разработки Xcode выполните:

```bash
./scripts/setup-local-signing.sh
./scripts/build-app.sh
```

Готовое приложение появится в `dist/Shoev Spell.app`. Словарь собирается автоматически из частей, которые лежат в репозитории.

Первый скрипт создаёт постоянную локальную подпись для сборок на вашем Mac. Это помогает сохранять системные разрешения при обновлениях. Закрытый ключ хранится вне репозитория.

Чтобы упаковать приложение в DMG:

```bash
./scripts/create-dmg.sh
```

Проверить исправление слов и правила пунктуации:

```bash
swift test
```
