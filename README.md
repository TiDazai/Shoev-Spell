# Shoev Spell

Локальная автоматическая проверка и осторожное исправление русских и английских слов во всех приложениях macOS, где разрешён глобальный ввод.

Текущий MVP использует встроенную базу из 7 120 939 записей, исправляет опечатки на расстоянии 1 только при высокой уверенности, пропускает защищённые поля и хранит локальный журнал исправлений.

## Установка

Скачайте `Shoev-Spell.dmg` со страницы Releases, откройте образ и перенесите приложение в `Applications`. При первом запуске разрешите «Мониторинг ввода» и «Универсальный доступ».

## Сборка

```bash
./scripts/build-app.sh
```

Готовое приложение появится в `dist/Shoev Spell.app`. При первом запуске macOS попросит разрешения «Мониторинг ввода» и «Универсальный доступ».
Скрипт автоматически скачает архив словаря из GitHub Releases, если его ещё нет локально.

Создание DMG:

```bash
./scripts/create-dmg.sh
```
